## Architecture and invariants

- Shipping runtime: native C#/.NET Framework + shared WebView2 + bundled aria2. No Electron, Node, Chromium or WebTorrent runtime in the native package. Optional media tools/shared prerequisites are separate downloads. Installer about 2.6 MB, Portable about 3.4 MB; use exact published sizes after CI.
- Keep blue/sky Baran identity, Persian RTL, adaptive sizing, All downloads startup, initially collapsed hamburger with 15-second outside timeout and persistent always-open preference.
- Native task windows share the existing core/WebView2 environment and are scoped to one task. Status/speed/completion tabs, overall progress, range map/connection rows, per-file HTTP caps, optional SHA-256, verified link replacement and close-on-completion option. Closing/hiding never pauses/deletes/restarts downloads; reopen from list/Enter/tray.
- Verified replacement compares resumable file identity before keeping offsets. Hash mismatch keeps partial data and blocks final publication; correcting expected hash can reuse it. Token budgeting fixes reproduced canceled-throttle debt under per-file AND global segmented resume. Stalled-body pause, HTML-as-archive rejection, collisions, stderr media/postprocessing and missing-FFmpeg guards have regressions.
- Persistent Inbox, bounded same-origin/folder scanner, separate Instagram view, scheduler/startup/tray, independent torrent down/up limits, media quality/playlist/audio and authorized cookies exist. Scanner cannot enumerate unlisted files; no arbitrary blob/POST/DRM/private-account bypass.
