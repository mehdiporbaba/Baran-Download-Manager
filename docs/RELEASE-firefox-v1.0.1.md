# Baran Firefox Extension `1.0.1` — Mozilla signed

[فارسی](#fa-firefox-v1-0-1)

Mozilla-signed Firefox extension 1.0.1 for Baran Download Manager. Install the signed XPI in ordinary Firefox (142+) with signature protection enabled. Then open Baran Settings → Browser integration → Firefox → Connect browser.

No Developer Mode or signature bypass is required. This is a self-distributed signed extension, not a public AMO store listing. Browser download handoff is optional in the extension popup.

Use the signed XPI rather than the older unsigned development package.

See [Firefox signing details](https://github.com/mehdiporbaba/Baran-Download-Manager/blob/main/docs/FIREFOX-SIGNING.md) for provenance and update limitations.
