# Pulse upstream review: v1.0.3 → v1.0.16

Reviewed on 2026-11-16: [33 upstream commits](https://github.com/TheGreatAzizi/Pulse-Download-Manager/compare/v1.0.3...v1.0.16). Baran ships the native Windows engine; the retained Electron engine is a separate compatibility path. Fixes are adapted to the relevant engine rather than assuming the original runtime still ships.

| Upstream change | Baran finding and action | Validation |
| --- | --- | --- |
| Tray Quit must use graceful shutdown (`8dc271f`) | Confirmed in retained Electron code: setting the shutdown guard before calling Quit skipped manager shutdown. Removed the premature guard. Native Quit already awaits Core.Stop, saves state and stops aria2. | Typecheck; native integration exits and restores persisted inbox. Electron Tray UI was not exercised. |
| Torrent listener fallback (`06b0d7b`) | Confirmed missing in both engines. Electron retries an OS-assigned port with bounded startup; failed fallback reports failure. Native aria2 tries the configured TCP/UDP port followed by ports 49152–65535. Firewall/forwarding rules for a fixed port may need updating. | A real local private torrent completes byte-for-byte while the configured TCP peer port is occupied. UDP/DHT collision is not exercised by this private-torrent fixture. |
| YouTube sign-in/private/age errors (`06b0d7b`) | Electron already had friendly errors. Added equivalent native guidance to select an authorized session in Settings > Tools. This does not bypass access restrictions. | Fixture CLI produces all three errors; each returns actionable settings guidance. |
| Absolute FFmpeg location (`06b0d7b`) | Electron could pass a bare executable name to yt-dlp; resolve PATH candidates to absolute files. Native custom and PATH candidates now return absolute paths too. | Typecheck and native compilation. Real FFmpeg merging was not exercised. |
| Final media file size (`06b0d7b`) | Native already verifies the output and reads its actual size. Ported actual-file size to Electron instead of estimated progress. | Native fixture deliberately reports 999 bytes; final task size matches the actual output. |
| GitHub transport robustness (`7932d84`, `06b0d7b`) | Search/release UI already exists. Added bounded transport retries to both engines; native now explains exhausted API limits and inaccessible repositories. HTTP errors are not retried automatically. | Local HTTP fixtures drop a connection, then return success, rate limit and 404; all pass. No live GitHub token used. |
| Windows names/icons (`cff9cf6`, `16b1055`, `87e9f9a`, `5dab8d5`, `4eabc10`, `dc4b369`) | Native already embeds Baran icon/name and assigns its window/tray icon. Move Electron name, app ID and existing Baran profile path before readiness. Pulse-specific shortcut deletion is not applicable to Baran identity. | Typecheck and native compile; Windows taskbar appearance not manually verified. |
| Installed auto-start / tray (`7932d84`, `b99e3fb`) | Already implemented independently in native settings, per-user startup and tray. Keep existing Baran behavior. | Existing settings and integration checks; no user startup setting changed during review. |
| Light theme, language, About/license (`07bad39`, `e57dfd6`) | Existing Baran theme, localization, About links and GPL license cover these changes. Preserve Baran blue palette and Persian documentation. | Source review. |
| Packaging, dependencies and signing workflows (`d4bf0ad`, `be334f9`, `44266ec`, `c2d2a59`, `322312c`, `5df678f`, `039c03f`, `83b4efe`, `1baa111`) | Native releases already enumerate deliverable assets, use npm ci for build tooling and exclude Electron/WebTorrent runtime. Security/dependency configuration exists. Upstream's removed signing configuration supplies no Windows signing certificate. | Source/workflow review; this review does not certify dependency security or signed Windows binaries. |
| Remaining version and screenshot-documentation commits | No engine fix to transplant. Keep Baran versions, links, screenshots and mandatory complete English/Persian release sources. | Release-note structural checks; translation quality still requires semantic review. |

Commands: `node --import tsx --test tests/*.test.ts`, `npm run typecheck`, `node tests/native.integration.mjs`, `node tests/connected.integration.mjs`, `node scripts/release-notes.cjs --check`. Native tests use isolated profiles, local media fixtures and a local torrent seeder; they do not test live YouTube accounts or public torrent DHT.

Port fallback follows the [official aria2 manual](https://aria2.github.io/manual/en/html/aria2c.html). A source/build verification is not a newly published desktop release. Firefox capture changes additionally require signing the updated extension before normal Firefox distribution.

<h1>بررسی اصلاحات بالادستی Pulse از نسخهٔ ۱.۰.۳ تا ۱.۰.۱۶</h1>

<p>در تاریخ ۲۰۲۶/۱۱/۱۶، <a href="https://github.com/TheGreatAzizi/Pulse-Download-Manager/compare/v1.0.3...v1.0.16">۳۳ کامیت بالادستی</a> بررسی شد. باران با موتور بومی ویندوز منتشر می‌شود؛ موتور باقی‌ماندهٔ Electron مسیر سازگاری جداگانه‌ای است. هر اصلاح به موتور مربوط تطبیق داده شده و وجود موتور قدیمی در بستهٔ منتشرشده فرض نشده است.</p>

<ul>
<li><strong>خروج از Tray — <span dir="ltr">8dc271f</span>:</strong> خطا در کد باقی‌ماندهٔ Electron وجود داشت: فعال‌شدن زودهنگام پرچم خروج باعث ردشدن توقف مرتب موتور می‌شد. آن انتساب حذف شد. خروج بومی از قبل منتظر توقف Core، ذخیرهٔ وضعیت و توقف aria2 می‌ماند. بررسی نوع‌ها و خروج و بازیابی صندوق در تست بومی انجام شد؛ رابط Tray نسخهٔ Electron به‌صورت عملی آزمایش نشد.</li>
<li><strong>پورت جایگزین تورنت — <span dir="ltr">06b0d7b</span>:</strong> در هر دو موتور کمبود تأیید شد. Electron با مهلت محدود، پورت انتخاب‌شدهٔ سیستم‌عامل را امتحان می‌کند و شکست تلاش دوم را خطا اعلام می‌کند. aria2 بومی پس از پورت TCP/UDP تنظیم‌شده، بازهٔ ۴۹۱۵۲ تا ۶۵۵۳۵ را امتحان می‌کند. قواعد فایروال یا انتقال پورت ثابت ممکن است نیاز به اصلاح داشته باشند. تورنت خصوصی محلی با پورت TCP عمداً اشغال‌شده، با محتوای کاملاً برابر دانلود شد؛ تداخل UDP/DHT در این تست خصوصی آزمایش نشد.</li>
<li><strong>خطاهای ورود، ویدیوی خصوصی و محدودیت سن یوتیوب — <span dir="ltr">06b0d7b</span>:</strong> Electron از قبل پیام مناسب داشت. راهنمای معادل برای انتخاب نشست مجاز در تنظیمات ← ابزارها به موتور بومی اضافه شد. محدودیت دسترسی دور زده نمی‌شود. ابزار آزمایشی هر سه خطا را تولید کرد و برنامه برای هرکدام راهنمای تنظیمات برگرداند.</li>
<li><strong>مسیر کامل FFmpeg — <span dir="ltr">06b0d7b</span>:</strong> Electron می‌توانست فقط نام فایل اجرایی را به yt-dlp بدهد؛ اکنون گزینه‌های PATH به مسیر کامل تبدیل می‌شوند. مسیر سفارشی و گزینه‌های PATH موتور بومی نیز کامل برگردانده می‌شوند. بررسی نوع‌ها و کامپایل بومی انجام شد؛ ادغام واقعی با FFmpeg آزمایش نشد.</li>
<li><strong>حجم نهایی فایل رسانه — <span dir="ltr">06b0d7b</span>:</strong> موتور بومی از قبل وجود خروجی و اندازهٔ واقعی آن را بررسی می‌کرد. خواندن اندازهٔ فایل واقعی به‌جای تخمین پیشرفت به Electron منتقل شد. ابزار آزمایشی بومی عمداً ۹۹۹ بایت گزارش داد و اندازهٔ نهایی ثبت‌شده با فایل واقعی برابر ماند.</li>
<li><strong>پایداری اتصال گیت‌هاب — <span dir="ltr">7932d84</span> و <span dir="ltr">06b0d7b</span>:</strong> رابط جست‌وجو و انتشارها از قبل وجود داشت. تلاش مجدد محدود برای خطاهای ارتباطی به هر دو موتور اضافه شد؛ موتور بومی اکنون تمام‌شدن سهمیهٔ API و مخزن غیرقابل‌دسترسی را توضیح می‌دهد. خطاهای HTTP خودکار تکرار نمی‌شوند. سرور محلی ابتدا اتصال را قطع و سپس موفقیت، اتمام سهمیه و خطای ۴۰۴ را شبیه‌سازی کرد؛ همهٔ بررسی‌ها موفق بودند. توکن واقعی گیت‌هاب استفاده نشد.</li>
<li><strong>نام و آیکون ویندوز — <span dir="ltr">cff9cf6</span>، <span dir="ltr">16b1055</span>، <span dir="ltr">87e9f9a</span>، <span dir="ltr">5dab8d5</span>، <span dir="ltr">4eabc10</span> و <span dir="ltr">dc4b369</span>:</strong> نسخهٔ بومی از قبل نام و آیکون باران را در فایل و پنجره و Tray داشت. تنظیم نام، شناسهٔ برنامه و مسیر موجود پروفایل Baran در Electron به پیش از آماده‌شدن برنامه منتقل شد. حذف میان‌بر مخصوص Pulse برای هویت باران کاربرد ندارد. بررسی نوع‌ها و کامپایل موفق بود؛ نمایش نوار وظیفهٔ ویندوز دستی تأیید نشد.</li>
<li><strong>شروع با ویندوز و Tray — <span dir="ltr">7932d84</span> و <span dir="ltr">b99e3fb</span>:</strong> تنظیمات بومی، اجرای خودکار برای همان کاربر و Tray از قبل مستقلاً پیاده شده‌اند و رفتار فعلی باران حفظ شد. بررسی‌های تنظیمات و یکپارچه‌سازی موجود اجرا شدند؛ هنگام بررسی، تنظیم اجرای خودکار کاربر تغییر نکرد.</li>
<li><strong>تم روشن، زبان و دربارهٔ برنامه/مجوز — <span dir="ltr">07bad39</span> و <span dir="ltr">e57dfd6</span>:</strong> تم، ترجمه‌ها، پیوندهای دربارهٔ برنامه و مجوز GPL باران این موارد را پوشش می‌دهند. رنگ آبی و مستندات فارسی باران حفظ شدند. این نتیجه از بررسی سورس به دست آمد.</li>
<li><strong>بسته‌بندی، وابستگی‌ها و گردش‌کار امضا — <span dir="ltr">d4bf0ad</span>، <span dir="ltr">be334f9</span>، <span dir="ltr">44266ec</span>، <span dir="ltr">c2d2a59</span>، <span dir="ltr">322312c</span>، <span dir="ltr">5df678f</span>، <span dir="ltr">039c03f</span>، <span dir="ltr">83b4efe</span> و <span dir="ltr">1baa111</span>:</strong> انتشار بومی از قبل فایل‌های قابل‌تحویل را مشخص می‌کند، برای ابزار ساخت از npm ci استفاده می‌کند و موتور Electron/WebTorrent را در بسته نمی‌گذارد. تنظیمات امنیت و وابستگی‌ها وجود دارد. تنظیم امضای حذف‌شدهٔ بالادستی، گواهی امضای ویندوز در اختیار ما نمی‌گذارد. بررسی سورس و گردش‌کار انجام شد؛ این بررسی گواهی امنیت وابستگی‌ها یا امضاداشتن فایل ویندوز نیست.</li>
<li><strong>باقی کامیت‌های شمارهٔ نسخه و تصاویر مستندات:</strong> اصلاح موتور برای انتقال ندارند. شماره‌ها، پیوندها و تصاویر باران و منابع الزامی کامل انگلیسی/فارسی انتشار حفظ شدند. بررسی ساختاری یادداشت‌های انتشار انجام شد؛ کیفیت ترجمه همچنان نیاز به بازبینی معنایی دارد.</li>
</ul>

<p>دستورهای بررسی: <span dir="ltr">node --import tsx --test tests/*.test.ts</span>، <span dir="ltr">npm run typecheck</span>، <span dir="ltr">node tests/native.integration.mjs</span>، <span dir="ltr">node tests/connected.integration.mjs</span> و <span dir="ltr">node scripts/release-notes.cjs --check</span>. تست‌های بومی از پروفایل جدا، ابزار رسانهٔ آزمایشی و فرستندهٔ تورنت محلی استفاده می‌کنند؛ حساب زندهٔ یوتیوب یا DHT عمومی را آزمایش نمی‌کنند.</p>
